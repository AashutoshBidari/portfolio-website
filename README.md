# Alchi Dude Portfolio

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser.

No build tools or frameworks are required. An internet connection is used only for Google Fonts; the site still works without them.

## Customize first
Open `script.js` and update the `portfolio` object:
- `name`
- `email`
- `github`
- `linkedin`
- `youtube`

Then edit the text in `index.html` to match your real experience and projects. The project cards are starter examples; update their status and links so you don't imply unfinished work is complete.

## Files
- `index.html` — page content and structure
- `style.css` — design, layout, responsiveness
- `script.js` — menu, current year, and contact/social links
